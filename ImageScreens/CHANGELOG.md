# Changelog


## 1.3.0 (2026-06-07)

Updated mod for Satisfactory 1.2.


## 1.2.0 (2026-05-10)

Mass replacement function.
- Added function to mass replace substrings in URLs in all existing screens.
- Fixed an issue where an error text wouldn't clear on clients in MP.


## 1.1.0 (2025-10-05)

Logging of used images.
- Added logging of all used images on load and save.
- Added a subsystem that is used to implement the logging.
- Removed original logging that was only happening on load.
- Removed debug logging.


## 1.0.0 (2025-06-29)

Initial release.
- Contains 12x8 landscape and 8x12 portrait screens.
- Supports static images and slideshows.
- Supports Satisfactory Clipboard.
- Multiplayer compatible.
- Slideshow settings are configurable.
- Supports localization, and is localized to Czech.
